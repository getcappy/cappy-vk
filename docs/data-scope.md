# 样本与时间范围

本项目使用 VK-LSVD 官方训练子集 `up-0.9_ip-0.9` 的前三个相对周（W0、W1、W2）。发布方按整个训练期的交互次数，分别排除了最活跃的 10% 用户和最热门的 10% 视频。因此，触达、留存和转化率描述这份样本中的行为。用户和视频维度来自全量元数据快照，覆盖的实体多于三周内实际出现的实体。[VK-LSVD 数据说明](https://huggingface.co/datasets/deepvk/VK-LSVD#data-description)

本项目按自定的[展示入口](dimensions/place.md)和[展示平台](dimensions/platform.md)字典解释这两列并保留原始编码。客户端、地域和性别继续按源编码展示。可观察到的事件是站内视频展示及其反馈。人数口径见[触达](metrics/audience/reach.md)。推送送达、登录、启动和注册时间需要各自的日志。

这三周的反馈标记可以描述收藏、分享和点踩等行为。判断新功能是否带来提升，需要实验分组、分流时间和结果窗口。判断沙盒用户是否满意，还需要相应的体验反馈。
