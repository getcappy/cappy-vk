# 三周收藏活动

这是用 VK 真实展示日志设计的回溯分析场景。运营想知道，在 W1 结束时放宽短视频的观看条件，会多圈出哪些用户，以及这些人在 W2 是否收藏过视频。日志记录的是用户的实际行为，未记录活动投放或实验分组。
