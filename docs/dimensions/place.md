# 展示入口

入口描述一次短视频展示发生在哪个产品页面。下表是 Cappy Demo 自定的业务字典，适用于 W0、W1、W2。VK 公开了入口类型的例子，原始数据只提供稳定的匿名编号。[VK-LSVD 匿名化说明](https://arxiv.org/html/2602.04567#S3.SS1)

| DWD `place_code`（ODS `place`） | Demo 入口名称 | 业务含义 |
| --- | --- | --- |
| 0 | 信息流 | 用户浏览首页动态时看到视频 |
| 1 | 短视频频道 | 用户进入专门浏览短视频的频道 |
| 2 | 社群 | 视频在群组或社区页面展示 |
| 3 | 个人主页 | 视频在个人资料页展示 |
| 4 | 消息通知 | 展示来源归入消息或通知入口 |
| 5 | 热门榜 | 视频在热门内容榜单展示 |
| 6 | 搜索结果 | 视频在搜索结果中展示 |
| 7 | 关注动态 | 视频在关注动态页展示 |
| 8 | 发现页 | 视频在发现页展示 |

其余非空值显示为“其他入口（编码 N）”，保留原编号以便下钻。“其他入口”合计包含所有未单独命名的非空编码。`NULL` 单列为“入口未知”。三周内观察到的编码以及未来新增的编码均按此规则处理。

按入口查数使用 `dwd_vk_video_exposure.place_code`。例如，“来自搜索的触达人数”在指定窗口筛选 `place_code = 6` 后按用户去重。源数据记录的是结果中的视频展示，一次搜索可能产生多条展示，搜索请求次数需要独立的搜索日志。“个人主页入口”使用 `place_code = 3`，“点击作者主页”使用同次展示上的反馈字段 `clicked_author`。

按入口或[平台](platform.md)输出有业务名称的结果时，在标题或注释标明“按 Demo 映射”。用户明确询问 VK 真实编号含义时，说明官方发布的匿名化范围。
