# 有序漏斗各步人数

先确定观察窗口、每步行为及顺序。到达第 k 步的人必须依次完成从第一步到第 k 步的行为，每步内按用户去重。

本项目的同周漏斗依次为[站内触达](../audience/reach.md)、[有效观看](../viewing/effective-views.md)、在更晚的一次展示中收藏。展示内的观看与收藏只能证明共现。按 `(week_no, source_row_no)` 判断不同展示的先后。数据支持排序，精确到小时的归因窗口需要额外时间戳。

[观看后收藏的有序漏斗示例](../../queries/ordered-funnel.sql)按用户比较第一次有效观看和最后一次收藏的行号。
