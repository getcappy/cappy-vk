# 强作者偏好用户占比

衡量在有足够观看记录的用户中，有多少人的有效观看集中在自己最常看的少数作者身上。可用于圈选偏好特定作者的用户，或比较不同人群的观看习惯。这里的“偏好”由实际观看行为推断，数据没有提供用户自报的喜好或关注关系。

1. **确定窗口和有效视频。** 以样本周为单位。在同一周，一次展示达到[常规有效观看](../viewing/effective-views.md)才纳入统计。同一用户对同一视频最多计一个，不同展示的观看秒数分别判定。只使用能识别作者的视频。
2. **确定可判定人群。** 用户当周有效观看至少 **10 个不同视频**才进入分母。观看记录不足的用户暂不打这个标签。
3. **在每个用户内部选作者。** 按该用户看过的不同有效视频数对作者降序排序，保留排名不超过 3 的作者，第三名并列者全部计入。作者不足三位时取全部。入选作者贡献的不同视频数，占这个用户全部有效视频数 **达到或超过 50%**，便给该用户打上“强作者偏好”标签。
4. **按人计算占比。** 分子为带标签的去重用户数，分母为可判定人群的去重用户数。每人权重相同，分母为零时返回 NULL。查询多周时分别报告各周结果。

例如，某用户当周有效观看了 12 个不同视频，其中前三位作者各贡献 2 个，合计 6 个，恰好达到门槛。另一位用户只看了同一作者的 3 个视频，即便这些视频看过很多次，仍属于样本不足。

从 `dwd_vk_video_exposure` 按周筛选，先按用户、作者统计不同视频数，再在用户内部排序。用户周表和视频周表分别汇总了两个维度，无法还原每位用户看过哪些作者。

并列按 `RANK() OVER (PARTITION BY user_id ORDER BY video_count DESC)` 处理。
