# 活跃 V2

“活跃人数”指指定窗口内做过约定行为的去重用户数。先确定哪种行为算活跃。提问只说“活跃”、报表也没有指定口径时，先确认要看观看还是某种互动。

**观看活跃人数**指同一周内[累计观看时长](../viewing/watch-time.md)严格大于 1800 秒（30 分钟）的去重用户数。恰好 1800 秒不计入，1801 秒计入。查询多周时，每周分别累计和判断。若要统计多周内有多少人曾达标，先逐周判断，再对达标用户按 `user_id` 去重。

用户周表每位用户每周一行，`watch_seconds` 已汇总该用户当周所有展示的观看秒数。以下示例按周统计 W0 至 W2，实际查询使用已确认的周范围。

```sql
SELECT week_no, SUM(IF(watch_seconds > 1800, 1, 0)) AS active_viewers
FROM dws_vk_user_week
WHERE week_no IN (0, 1, 2)
GROUP BY week_no
ORDER BY week_no;
```

**互动活跃人数**按业务方指定的动作统计。例如，当约定为“点赞或收藏”时，在指定窗口取两类用户的并集，同一用户完成两种动作仍只计一人。回答时写出采用的行为和窗口。登录或启动活跃需要相应的事件日志。
