# 周爆款视频（Demo 试用口径）

一位作者在该样本周有至少一条作品同时达到观看规模、点赞和收藏或分享门槛，就记为当周产出爆款的作者。以每个 `(week_no, item_id)` 为单位独立判定，适用于本项目 W0–W2 样本。

| 同周单条视频需要满足的条件 | 计数方法 |
| --- | --- |
| 合格观看至少 500 次 | 单次展示观看至少 10 秒计一次。已知时长为 1–9 秒的作品看完即可计一次。该短片规则专用于爆款评估。 |
| 点赞至少 20 次 | 统计当周该视频全部展示中的点赞次数。 |
| 收藏至少 2 次，或分享至少 3 次 | 两类反馈各自累计，任一达标即可。 |

用视频周表 `dws_vk_video_week` 关联 `dim_vk_video` 的 `item_id`。时长 1–9 秒时取 `observed_completions`，其余取 `watches_10s`。点赞、收藏和分享分别取 `likes`、`bookmarks` 和 `shares`。反馈与观看都是作品周累计，允许来自不同观众。源数据记录了打开评论区，实际发表评论数需要评论事件。

同周将达标视频按 `item_id` 计数，产出爆款的作者按 `author_id` 去重。某作者的周爆款率分母取其当周在样本中有展示的作品数，分子取其中达标的作品数。无展示作品和发布时间无法从本项目确定。查询多周时先逐周判定，再按问题汇总。各阶段表示满足条件的作品逐级减少，数据没有提供视频达到各门槛的具体时刻。

门槛以 W1 校准并固定用于三周。W1 有展示视频的合格观看次数第 99.9 百分位为 493。在至少 500 次合格观看的作品中，点赞次数第 75 百分位为 16，收藏次数第 95 百分位为 2，分享次数第 75 百分位为 2。原始数据筛除了整个训练期最热门的 10% 视频，阈值解释限于[当前样本](../../data-scope.md)。
