# 沉默核心用户有效回流率

衡量一批原本投入观看、也愿意收藏或分享的用户，在短暂沉默之后，有多少人恢复了观看习惯。这个指标描述样本中观察到的行为，判断推送或运营活动带来的增量需另有触达或实验数据。

以用户指定的回流周为 T，使用三个连续且数据完整的相对周。以 W2 为 T 时，各阶段如下。

| 阶段 | 用户入选条件 |
| --- | --- |
| 核心周 T−2（W0） | 同周达到[观看活跃 V2](../audience/acticity_V2.md)（累计观看严格大于 1800 秒），且至少有一次[收藏](../feedback/bookmark-count.md)或[分享](../feedback/share-count.md)。两种行为均发生仍只算一人。 |
| 沉默周 T−1（W1） | 从上述核心用户中，保留当周累计观看不超过 60 秒、收藏和分享次数均为 0 的用户。完整周内没有该用户的记录，三项按 0 计。 |
| 回流周 T（W2） | 从沉默名单中，统计当周重新达到观看活跃 V2 的用户。此阶段只考察观看恢复，单次短暂回访不足以达标。 |

**分母**是沉默周结束时已确定的全部沉默核心用户。**分子**是其中在回流周重新达标的去重用户数。有效回流率 = 分子 ÷ 分母，以百分比展示。回流周缺席者保留在分母中。分母为空时返回 NULL。

按 `user_id` 对齐三周。可从 `dws_vk_user_week` 读取每个用户每周的 `watch_seconds`、`bookmarks` 和 `shares`。沉默周累计恰好 60 秒且没有收藏或分享者可以入选。回流周累计恰好 1800 秒仍未达标。任一整周数据缺失时，此窗口无法评估，区别于某个用户在完整周内没有记录。
