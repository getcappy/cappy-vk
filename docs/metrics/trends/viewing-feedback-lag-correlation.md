# 有效观看率与次周收藏分享率的变化相关性

用户开始更认真地看视频之后，下一周是否也更常收藏或分享？这个指标把同一用户前后两段行为变化配成一对，用于判断观看趋势能否提示后续互动趋势。

## 两条周趋势

| 每位用户、每个相对周 | 分子 | 分母 |
| --- | --- | --- |
| 有效观看率 | 达到[常规有效观看](../viewing/effective-views.md)的展示次数 | 该用户当周全部展示次数 |
| 收藏分享率 | 发生[收藏](../feedback/bookmark-count.md)或[分享](../feedback/share-count.md)的展示次数。同一展示两者都有只计一次 | 该用户当周全部展示次数 |

选三个连续且数据完整的相对周。为减少偶尔刷到一两个视频造成的波动，本项目要求同一用户在**每一周至少有 10 次展示**。三周都使用这一固定人群。周度趋势先计算每个人的比率，再取人均值，每人权重相同。展示明细可识别同一展示上的两个反馈，用户周表只保留两种动作各自的计数。

## 如何检验两段变化

以 W0、W1、W2 为例。对每个入选用户，计算 X = W1 有效观看率 − W0 有效观看率，Y = W2 收藏分享率 − W1 收藏分享率，变化用百分点表示。从 20% 升到 25% 记作 +5 个百分点。没有互动但当周有足够展示时，收藏分享率为 0。保留变化为 0 的用户。

在所有用户的 (X, Y) 配对上计算 Pearson 相关系数，同时报告配对人数和两条周趋势。正值表示观看率增幅较大的用户，随后互动率的增幅也倾向较大。负值表示方向相反。接近 0 表示两段变化之间的线性关系很弱。有效配对少于两人或任一变量没有变异时，结果记为 NULL。中间步骤保留精度。

系数描述连续三周有足够展示的用户间的差异。三个全站周均值只能描述总体走势。两段变化共用中间周，内容和推荐曝光也会影响两种行为，因果解释需要独立的实验或识别设计。
